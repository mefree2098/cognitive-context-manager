# Code Of Conduct

## Our Pledge

We want this project to be a welcoming, practical place to improve local-first context tooling for Codex users. Participants are expected to be respectful, constructive, and mindful that security and privacy topics can involve sensitive user data.

## Expected Behavior

- Be respectful and collaborative.
- Assume good intent while staying precise about risks.
- Keep issues and pull requests focused on the project.
- Redact private data, secrets, logs, and memory exports before sharing.
- Accept maintainer decisions about scope, safety, and release readiness.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information, credentials, tokens, raw memory exports, or unredacted logs.
- Encouraging users to bypass safety, privacy, or instruction-precedence protections.
- Spam, trolling, or repeated off-topic comments.

## Enforcement

Maintainers may edit, hide, or delete comments; close issues or pull requests; or block participants whose behavior is harmful to the project or its users.

Report conduct issues privately through the maintainer's GitHub profile. Do not include unnecessary private data in reports.
