# Memory Taxonomy

- `episodic`: one event in a session.
- `semantic`: stable project facts, decisions, architecture notes, and conventions.
- `procedural`: durable workflow rules or user/process preferences.
- `salience`: high-friction or high-urgency context.
- `open_loop`: unresolved tasks, questions, blockers, or TODOs.
- `artifact`: known state of files, docs, tests, generated outputs, and diffs.
- `safety`: redacted safety/security events and risky command patterns.

Every memory includes confidence, salience, provenance, and staleness fields.
